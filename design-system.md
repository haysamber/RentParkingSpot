# Design System

## Typography

| Role       | Font      | Weight | Size      |
|------------|-----------|--------|-----------|
| Primary    | Inter     | —      | —         |
| H1         | Inter     | 700    | 2.25rem   |
| H2         | Inter     | 700    | 1.5rem    |
| Body       | Inter     | 400    | 1rem      |
| Small/Label| Inter     | 500    | 0.875rem  |

No secondary font. Inter is used for all text.
